# 規約・運用ルールの起草規範

自分で書く利用規約や運用ルールを、法令と同様に解釈できる文章にする。この規範は、資料で確認できた項目を一つずつ足して育てる。ここに書かれていない事項は、確認済みの規範がないものとして扱い、推測で断定しない。

## 表記

### 接続詞

- 「及び」「並びに」「又は」「若しくは」は、接続詞でも漢字で書く。
- 上記以外の接続詞は、原則として仮名で書く。「おって」「かつ」「したがって」「ただし」「ついては」「ところが」「ところで」「また」「ゆえに」など。

出典（引用日はいずれも 2026-10-09）:

- 常用漢字表の実施に伴う公用文及び法令における漢字使用等について（昭和56年10月5日 総第187号）: https://www.mhlw.go.jp/web/t_doc?dataId=00ta0025&dataType=1&pageNo=1
- 法令における漢字使用等について（平成22年11月30日 内閣法制局長官決定）を掲載したとされるページ: https://www5d.biglobe.ne.jp/Jusl/Bunsyo/BunHoureiH22.html 。接続詞の扱いが昭和56年のものと同じであることを確認した。ただし、取得結果の見出しが「公用文における漢字使用等について」となっており、ページの同一性は完全には確認できていない。
